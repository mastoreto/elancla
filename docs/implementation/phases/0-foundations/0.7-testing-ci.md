# 0.7 — Tests y CI

## Objetivo

Que nada crítico se pueda romper sin que CI lo frene.

## Depende de

Arranca junto con 0.2 y crece con cada subfase.

## Alcance

- Tarea `test` en `turbo.json` y scripts por workspace (`bun test`).
- Postgres de test (servicio de `docker-compose` y servicio en CI), `migrate deploy`, aislamiento por test.
- Factories de datos y cliente HTTP de test (`app.request`).
- Runner de la matriz de autorización.
- Playwright para el CRM con usuarios sembrados por rol.
- GitHub Actions: `check`, `check-types`, unitarios, integración, E2E. Protección de rama en `main`.

## Fuera de alcance
