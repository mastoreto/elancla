# 0.6 — Archivos y multimedia

## Objetivo

Subir y servir imágenes públicas y documentos privados de forma segura y gratis.

## Depende de

0.2, 0.4, 0.5.

## Alcance

- `core/storage`: puerto `FileStorage` (`presignUpload`, `presignDownload`, `head`, `delete`). Evaluar un único adaptador S3-compatible (B2 en producción, MinIO en `docker-compose` local).
- Buckets B2 público y privado; keys de aplicación con permisos mínimos.
- `media.<dominio>` en Cloudflare con caché larga para el bucket público.
- Módulo `media`: presign de subida (clave generada por el servidor, 5 min, tipo y tamaño atados), `finalize` (verifica magic bytes y tamaño), variantes `webp`/`avif` en varios anchos para imágenes.
- Descarga privada: URL firmada de 60 s tras autorizar y auditar.
- Cron que borra subidas no finalizadas.

## Fuera de alcance

Video. Edición de imágenes en el CRM.

## Requisitos ESRE / decisiones

ESRE 2.2 (digitalización de facturas); D-06.

## Cambios de BD

`File` (organización, bucket, clave, tipo, tamaño, checksum, estado, variantes, subido por).

## Endpoints y permisos

`POST /media/uploads`, `POST /media/uploads/:id/finalize`, `GET /media/:id/download` con `media:*` + permiso del recurso dueño.

## Tests obligatorios

- Archivo con extensión falsa (tipo real distinto) → rechazado en `finalize`.
- URL privada no se emite sin permiso; cada emisión queda auditada.
- El adaptador pasa la suite de contrato del puerto.

## Terminado cuando

- Tests obligatorios en verde en CI.
- `bun run check` y `bun run check-types` limpios.
- Docs de `architecture/` actualizados si algo cambió.
