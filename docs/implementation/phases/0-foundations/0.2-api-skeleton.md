# 0.2 — Esqueleto de la API

> **Implementada** en la rama `feat/api-skeleton`. Desvíos: CSRF propio sobre `hono/csrf` (ver
> `security.md`), `dynamic = "force-dynamic"` en el layout raíz del CRM para que todas las páginas
> lleven nonce de CSP, límite de página > 100 → 400, env de la API en `apps/api/src/core/env`,
> idempotencia diferida a 2.1.

## Objetivo

Tener `apps/api` funcionando con todo el `core/` transversal, montada en el CRM, antes de escribir el primer módulo de negocio.

## Depende de

0.1.

## Alcance

- `apps/api` con Hono según [`api-structure.md`](../../architecture/api-structure.md).
- `core/context`, `core/errors` (Problem Details), `core/db` (transacción), `core/tenancy` (extensión Prisma que filtra por organización).
- `core/http`: request id, cabeceras de seguridad, CSRF (`Origin` + `Sec-Fetch-Site`), solo JSON en mutaciones, límite de body, paginación por cursor, idempotencia.
- `packages/contracts` creado; generación de OpenAPI con `@hono/zod-openapi`.
- Montaje en `apps/crm/app/api/[[...route]]/route.ts`; cliente tipado en `apps/crm/lib/api` (browser + in-process para RSC).
- `apps/crm/middleware.ts` → `proxy.ts` (redirect optimista, rewrites por slug, nonce de CSP).
- `packages/env` con schema por app; variables obligatorias sin `optional()`.
- `GET /health` sin datos sensibles.

## Fuera de alcance

Auth real (0.3), permisos (0.4), módulos de negocio.

## Requisitos ESRE / decisiones

D-07, D-22, D-24; [`backend.md`](../../architecture/backend.md), [`security.md`](../../architecture/security.md).

## Endpoints y permisos

`GET /health` (público).

## Tests obligatorios

- Cada error de dominio se traduce al status correcto, sin stack en la respuesta.
- Mutación con `Origin` ajeno o `Content-Type` de formulario → rechazada.
- Body con campos desconocidos → 400.
- La extensión de tenancy no devuelve filas de otra organización (dos orgs de prueba).
- El cliente in-process de RSC reenvía cookies.

## Terminado cuando

- Tests obligatorios en verde en CI.
- `bun run check` y `bun run check-types` limpios.
- Docs de `architecture/` actualizados si algo cambió.
