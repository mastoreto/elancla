# 1.8 — Galería

> **Diferida** (D-37): fuera de la primera versión. Se conserva como base para cuando se retome.

## Objetivo

Álbumes de fotos publicados en la web.

## Depende de

1.0, 1.1.

## Alcance

- Álbumes con fotos (vía `media`), orden, portada, visibilidad.
- Página nueva en la web (requiere diseño en la dirección visual acordada).

## Fuera de alcance

Lo que 1.0 marque como fijo.

## Requisitos ESRE / decisiones

—

## Cambios de BD

`GalleryAlbum`, `GalleryPhoto`.

## Endpoints y permisos

`content/gallery` con `content.gallery:*`.

## Tests obligatorios

- Álbum oculto no sale en la API pública.
- Fotos solo de `File` públicos y finalizados.

## Terminado cuando

- Tests obligatorios en verde en CI.
- `bun run check` y `bun run check-types` limpios.
- Docs de `architecture/` actualizados si algo cambió.
- La sección de la web muestra datos de la API, sin seeds.
