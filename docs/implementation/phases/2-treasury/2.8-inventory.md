# 2.8 — Inventario

## Objetivo

Registro del equipamiento de la iglesia.

## Depende de

Base técnica (0.x); 1.5 (ministerios).

## Alcance

- Ítem (`INV-…`): nombre, categoría, ubicación, ministerio responsable, estado, fecha y valor de
  adquisición, fotos.
- Historial de cambios de estado y asignación.
- Vínculo opcional con el movimiento de compra.

## Fuera de alcance

Amortización contable.

## Requisitos ESRE / decisiones

ESRE 1.3 (registro de inventario).

## Cambios de BD

`InventoryItem`, `InventoryEvent`.

## Endpoints y permisos

`treasury/inventory` con `inventory:*`.

## Tests obligatorios

- Alcance `ministry` ve solo el inventario de su ministerio.
- Cambio de estado queda en el historial.

## Terminado cuando

- Tests obligatorios en verde en CI.
- `bun run check` y `bun run check-types` limpios.
- Docs de `architecture/` actualizados si algo cambió.
- La pantalla del CRM usa la API, sin seeds.
