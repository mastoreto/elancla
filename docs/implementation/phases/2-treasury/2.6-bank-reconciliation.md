# 2.6 — Conciliación bancaria

## Objetivo

Importar extractos y conciliarlos contra los movimientos (D-47).

## Depende de

2.1.

## Alcance

- Plantillas de importación por banco (sugeridas por país) + importador genérico con mapeo de
  columnas guardable (D-51).
- Vista previa antes de importar; detección de líneas ya importadas.
- Sugerencia de coincidencias (fecha, monto, referencia); confirmar, crear movimiento desde la línea
  u observar.
- Estado por movimiento: conciliado / pendiente / observado.

## Fuera de alcance

Conexión directa con bancos (open banking).

## Requisitos ESRE / decisiones

D-47, D-51.

## Cambios de BD

`StatementImport`, `StatementLine`, `ImportTemplate`, estado de conciliación en `Movement`.

## Endpoints y permisos

`treasury/reconciliation` con `reconciliation:*`.

## Tests obligatorios

- Reimportar el mismo extracto no duplica líneas.
- Plantillas probadas con extractos de ejemplo reales (anonimizados) de cada banco soportado.
- Archivo malformado → error claro, nada importado.

## Terminado cuando

- Tests obligatorios en verde en CI.
- `bun run check` y `bun run check-types` limpios.
- Docs de `architecture/` actualizados si algo cambió.
- La pantalla del CRM usa la API, sin seeds.
