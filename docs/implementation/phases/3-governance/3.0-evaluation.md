# 3.0 — Evaluación de gobierno

> **Completada** (2026-11-18). Resultado: D-53. Las votaciones se construyen sobre las bases
> definidas, posiblemente después de la primera versión.

## Respuestas

- **Qué se vota**: mociones, solo en asambleas.
- **Estatuto**: elección de directiva con voto secreto; el resto, mano alzada (voto abierto).
- **Padrón**: existe el registro de membresía de la iglesia; vive en el sistema.
- **Quién vota**: solo los presentes acreditados (presencial o virtual).
- **Forma**: voto electrónico (logueado o con código de un solo uso) + registro por el moderador para
  quien no tenga celular.
- **Exportación**: los resultados no salen del sistema.
